# lumen.liliumapps.com

Website for Lumen, the file manager by Lilium Apps: the landing page and the
app's privacy policy at `/privacy/` (the URL listed on Google Play).

```bash
npm install
npm run develop   # http://localhost:8000
npm run build     # static site in public/
```

Pushing `main` deploys to GitHub Pages. Icons in `static/` come from the
app's Play listing (`LumenFileManager` repo, generated by
`branding/apps/lumen-files/store.mjs`). The social image, `og-image.png`, is the
Play feature graphic (`branding/listing`); copy it again when that changes.

The landing page shows the app in phone frames (`src/components/PhoneScreen.js`):
`static/screens/<name>.webp`, 720 × 1616 screenshots of the release build with
the demo files (`../demo`) and Android's demo status bar.
